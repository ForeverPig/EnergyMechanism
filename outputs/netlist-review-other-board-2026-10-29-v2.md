## 2. 主要剩余问题：USB与降压输出没有完整的供电隔离

目前实际连接：

`24V VIN → D1 → JW5026 → L1 → 系统5V`

`USB VBUS → D9(DSK110) → 系统5V`

D9方向正确，可以阻止系统5V正常直流回灌USB VBUS；但降压支路没有输出隔离，USB会同时给JW5026的输出端加电。JW5026是同步降压，手册没有给出输出端断电防反灌保证，不能默认USB单独供电时降压支路会被隔离。

可能的反向路径为系统5V→L1→SW→片内功率结构→降压输入节点。D1有助于阻止该节点进一步反向给外部VIN接口供电，但不隔离JW5026本身。具体反向电流、输入节点电压和启动表现未实测，不作运行结果断言。

建议按先前配置说明，将BUCK输出与USB输入通过带反向阻断的低压降电源MUX汇入系统5V，例如TPS2116；或采用两路完整的低压降理想二极管方案。不能只移除BUCK侧二极管就认定双电源问题全部解决。

建议网络分开：

`JW5026 + L1 + 输出电容 + R27反馈上端 → 5V_BUCK`

`5V_BUCK → MUX输入1；USB VBUS → MUX输入2；MUX输出 → SYS_5V`

JW5026反馈从MUX之前的5V_BUCK取样。系统CAN、LDO等由SYS_5V供电。

## 3. USB单独供电时的CAN欠压风险仍未消除

D9仍为DSK110，USB供电到五个TJA1051的VCC之间仍有二极管压降。

TJA1051推荐VCC至少4.5V。例如USB入口为4.75V时，D9和布线总共只允许损失0.25V；当前不能保证在多路CAN/Wi-Fi负载下始终满足。该风险仅说明余量没有得到保证，不等于断言所有USB供电都会失败。

JW5026改版已经解决正常24V供电时原输出串联二极管导致的压降；USB路径仍要独立解决。低压降MUX可同时处理本节和上一节，但不能提高USB端口本身的供电能力。

来源：[NXP TJA1051手册](https://www.nxp.com/docs/en/data-sheet/TJA1051.pdf)、[TI TPS2116手册](https://www.ti.com/lit/ds/symlink/tps2116.pdf)。

## 4. SMF26A钳位与JW5026耐压余量

当前D2器件属性：VRWM=26V，VCLAMP=42.1V@4.8A，峰值功率200W（指定脉冲条件）。26V是反向截止电压，不能当作浪涌时把输入固定钳在26V。

JW5026推荐输入最高40V、VIN绝对最大44V。42.1V已高于推荐工作上限，距44V仅1.9V；还没有计入PCB寄生电感引起的额外尖峰。

不能据此直接断言24V应用必然损坏：实际钳位取决于脉冲电流、波形和布局。但当前TVS规格不足以直接证明输入保护有充分余量。需按24V电源最高持续电压、线缆及目标浪涌选择截止电压/功率，并确认芯片脚上的峰值。不要在不知道电源最高值和瞬态要求时，仅把26V改为24V了事。

TVS并非完整的持续过压保护，D1也不是保险丝；还应明确上游限流/保险条件。

依据：SMF26A参数来自本次网表；JW5026耐压来自[原厂手册第2页](https://datasheet.lcsc.com/datasheet/pdf/f83872ed2237628ee0705043f9e45a8d.pdf?productCode=C185109)。
