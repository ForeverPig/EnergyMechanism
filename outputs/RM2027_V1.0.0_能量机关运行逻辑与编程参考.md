主要出处：§4.3.2.3，印刷页54–55（PDF第55–56页）；§5.6.3及§5.6.3.1，印刷页97–101（PDF第98–102页）。下文页码均为印刷页。

本文是旋转、灯效和命中判定的实现参考，未修改STM32工程。标注“建议”“推导”或“未明确”的内容不属于官方额外规定。

## 1. 总体模型

- 5个物理灯臂，均匀分布，间隔72°；每臂一个圆靶。
- 圆靶实体最大直径308 mm，有效检测直径300 mm。（页54–55）
- 红蓝双方共轴旋转，从各自正面看旋转方向相反；双方激活状态独立。（页97）
- 比赛中持续旋转：未激活、激活失败和已激活都不意味着停转。
- 官方四种状态：未激活、正在激活、已激活、激活失败。（页99–101）
- “激活失败”是重置正在激活流程；20秒机会超时才返回未激活。建议在软件中把失败作为瞬时事件处理。

建议分为三层：比赛/命中状态机、连续运行的电机控制、按状态渲染的LED效果。不要用灯效阻塞延时驱动整套逻辑。

## 2. 阶段、机会与总计时（页97）

| 项目 | 小能量机关 | 大能量机关 |
| --- | --- | --- |
| 阶段 | 比赛开始至3分钟 | 比赛开始3分钟后 |
| 发放机会时刻（比赛已进行时间） | 0、90秒 | 180、255、330秒 |
| 机会累积 | 可以 | 可以 |
| 发起方式 | 步兵操作手选手端，或哨兵串口 | 同左 |
| 发起前状态 | 未激活 | 未激活 |
| 一次激活窗口 | 20秒 | 20秒 |
| 成功后的保持时间 | 45秒 | 按有效命中计数，30–60秒 |

机会到账不等于自动点靶，须有触发命令。建议用发放事件位图避免在同一时刻的多个调度周期重复加机会。

实现建议：接受一次启动命令时消耗一次机会，记录固定的 `attempt_deadline`；本次窗口内打错/超时只重置进度，不重新发放机会、不延长总窗口。手册未逐项规定扣机会时刻及重试时20秒计时器的实现方式，应将此作为实现约定，而非引用成明确原文。

## 3. 旋转（页97）

### 3.1 方向

每局开始前随机一次方向，该局不改变。换靶、失败、成功以及小大阶段切换都不能重新抽方向。

软件建议：`dir` 取+1或-1，所有速度函数输出非负速度幅值，最后乘方向符号。

### 3.2 匀速

小能量机关全程，以及非正在激活状态的大能量机关：

`speed = π/3 rad/s ≈ 1.0471976 rad/s = 60°/s = 10 rpm`

上述是机关输出轴速度。电机速度需按实际减速比换算。

### 3.3 大能量机关正在激活

`speed(t) = a * sin(ω * t) + b`

- `a ∈ [0.780, 1.045]`
- `ω ∈ [1.884, 2.000]`
- `b = 2.090 - a`，不能独立随机。
- `t` 单位秒，速度单位rad/s。
- 原文规定每次进入“可激活状态”时参数重置：`t=0`，`a`和`ω`重新取范围内任意值。
- 实际转速与目标函数的时间误差在500 ms内；这不是500 ms的控制更新周期。

数学推导：周期约3.142–3.335秒；峰值恒为2.090 rad/s；谷值为`2.090-2a`，范围0–0.530 rad/s。速度幅值不会变负，不能把正弦项直接当最终速度，否则会产生错误反转。

建议控制接口：

```c
// 仅示意：t_s为单调时钟与曲线起点之差，单位秒。
float speed_abs = use_big_curve
    ? a * sinf(omega * t_s) + (2.090f - a)
    : PI / 3.0f;
float output_rad_s = direction * speed_abs;
float output_rpm = output_rad_s * 60.0f / (2.0f * PI);
// motor_rpm = output_rpm * 实际减速比；方向按安装校准。
```

参数只在规定的进入事件中抽取，不在每次控制循环或每次换靶时随机。成功/机会结束后回到匀速，电机仍持续运行。

## 4. 小能量机关命中流程（页100–101）

1. 清空本次进度，随机选5块靶中的1块作为当前目标。
2. 目标圆靶显示图5-21的可激活图案，对应灯臂中轴显示箭头流动灯效。
3. 在2.5秒内命中当前目标，则该臂完成，显示完成灯效；再从未完成灯臂中随机选下一块。
4. 已完成灯臂保留完成显示；累计完成5块进入已激活，保持45秒。
5. 任一步超过2.5秒未命中，或命中非随机点亮的装甲模块，则激活失败，重置当前流程。
6. 从本次外部触发起20秒仍未成功，返回未激活。

建议用5位 `done_mask` 保存进度，选择范围为 `all_arms & ~done_mask`。这里是5个不同物理灯臂依次完成。

## 5. 大能量机关命中流程（页100–101）

1. 每轮从全部5块装甲中随机选2块不同装甲，均显示可激活图案和对应箭头流动灯效。
2. 从本轮显示目标起，2.5秒内命中其中任意一块的可检测区域，该轮即满足“激活一组”的条件。
3. 第一靶命中后改变相应灯效，并从这一命中时刻开启1秒补击窗口。
4. 这一秒内可命中另一块目标；第二靶未命中不导致本轮失败。
5. 本轮结算后重新从全部5块中选2块，跨轮允许重复相同物理灯臂。
6. 连续完成5组后激活成功。每组至少1次、至多2次计入命中，最终有效计数为5–10。
7. 首击等待超出2.5秒，或击中非随机点亮装甲，则失败并重置流程。
8. 整次尝试仍受20秒窗口限制。

这里的“5组”是5轮双靶，不能用“5个物理灯臂都打中过”判成功。

进度灯：完成第1组并开始第2组时，灯臂中部显示约1/5；完成第2组并开始第3组时显示约2/5，依次增加。不要按成功命中的物理灯臂编号来显示大能量机关总进度。

建议将“该组首击成功”“完成该组结算”“可见进度更新”分开。第5组也保留补击机会后再结算整体结果，否则最多只能记9次命中，与表5-23的10次结果不符。

原文未精确说明第二靶提前命中后是立即换组，还是等满1秒换组；应配置为明确的训练策略，不把其中一种称为官方精确时序。

## 7. 命中环数及已激活持续时间（页98–99）

| 本局此前大能量成功次数 | 当前可检测环数 |
| --- | --- |
| 0 | 1–10环 |
| 1 | 4–10环 |
| 2 | 7–10环 |

成功次数是本方大能量的累计成功次数，不能用轮数或命中数代替；失败不增加成功次数。超出有效检测环的击打不应计入有效命中。

图5-17中圆靶有效半径150 mm，10环从中心向外排列，每一环径向宽15 mm；1环最外，10环最内。边界归属需自行规定或依据官方检测协议，不能由插图认定恰在边界时如何舍入。官方说明检测精度为径向1 mm。

| 平均环数 | 攻击增益（手册原口径） | 防御增益 | 热量冷却增益 |
| --- | --- | --- | --- |
| [1,3] | 150% | 25% | 无 |
| (3,7] | 150% | 25% | 2倍 |
| (7,8] | 200% | 25% | 2倍 |
| (8,9] | 200% | 25% | 3倍 |
| (9,10] | 300% | 50% | 5倍 |

平均环数建议按本次成功流程内有效命中的环数总和除以有效命中数计算，重试时清空当前流程统计。不要将未命中的可选第二靶计为0环；这属于对“击中的平均环数”的实现解释。大能量成功时另有750点经验由己方存活步兵平分。

小能量成功提供45秒25%防御增益，并在增益期间为步兵提供额外100%经验，本方一次增益期间额外经验合计最多1200点。只做训练机关时，可保留成功持续时间和结果输出，而不实现机器人增益分发。

## 8. 建议的软件状态和变量

```text
顶层：IDLE / ACTIVATING / ACTIVE
失败事件：FAIL -> 清本次流程进度 -> ACTIVATING（总窗口尚未结束）
激活子状态：WAIT_FIRST_HIT / WAIT_SECOND_HIT / SWITCH_BLANK

match_start, mode, direction
chance_small, chance_big, granted_event_mask
attempt_deadline                 // 20秒，外层尝试
first_hit_deadline               // 2.5秒，每轮首击
second_hit_deadline              // 1秒，大能量补击
blank_deadline                  // <=200 ms，切换灭灯
active_deadline                 // 45秒或查表30–60秒
target_mask, hit_mask            // 当前组目标与已命中目标
small_done_mask                 // 小能量不同物理臂的进度
big_completed_groups            // 大能量0–5轮进度
valid_hit_count, ring_sum        // 当前流程计分
big_success_count               // 本局已成功次数，决定有效环数
a, omega, b, curve_start         // 连续旋转曲线
```

推荐处理顺序：读取带时间戳的命中事件；根据事件时间判断窗口；处理状态转移与超时；根据最终状态生成灯效；独立更新电机目标。事件恰好在边界时的接纳规则要统一，不能由任务执行先后偶然决定。

物理击打信号应先经消抖/事件合并，再进入规则层。一个弹丸引起的多个ADC峰不能累计多次；消抖阈值与重击屏蔽时间需要实测，手册没有提供训练板算法参数。

## 9. V1.0.0未明确的边界，需作为策略参数保留

1. 共轴但红蓝状态独立：一侧正在激活大能量、另一侧未激活/已激活时，单根轴如何仲裁速度；另一侧随后发起时是否重新抽曲线。原文未明确。单面训练实现可避开该问题；双面系统必须共用一个运动控制器。
2. 旋转段使用“可激活状态”，状态列表使用“正在激活”；失败重置是否重抽a、ω并重置t没有逐项说明。建议初版仅在外部新尝试开始时重置曲线，普通换靶和内部失败不重抽，标为训练策略。
3. 20秒窗口内重试是否重置总时间、机会具体扣除时刻未给算法级定义。建议采用固定外层20秒窗口，防止持续失败无限延长。
4. 小大阶段在180秒边界的切换、跨阶段未结束的激活/增益、小能量剩余机会如何处理未说明。
5. 大能量第二靶提前命中后的换组时刻、第五组完成与20秒总超时同时发生时的优先级未说明。
6. 换靶灭灯期的命中、重复命中已打过的当前组靶、不可检测外环与打错靶的组合判定未说明；应区分“没有有效检测事件”与“有效事件打错目标”。
7. 灯效动画参数、电机加减速曲线、比赛结束停机过程未给出；根据硬件能力单独设计，不称为官方规定。

## 10. 后续实现验收用例

- 空闲和成功期间仍以10 rpm转动；换靶不会停车；一局方向始终固定。
- 大能量正弦曲线参数在范围内，b受约束，周期/峰谷正确，时间单位为秒。
- 小能量连续完成5个不同臂成功；错靶和首击超时重置进度。
- 大能量每轮只打首靶也可成功，5次命中保持30秒；每轮双中为10次，保持60秒。
- 大能量允许连续轮次出现相同物理靶，不使用小能量的排除已完成靶算法。
- 第二靶未中不失败；第一靶命中后重新开始1秒计时。
- 第五组保留补击窗口，正确累计最后一次可选命中。
- 20秒结束后停止本次激活尝试，失败重试不会无限延长（按本文建议策略）。
- 切换灭灯不超过200 ms，不阻塞电机调度。
- 成功一次后只接受4–10环，成功两次后只接受7–10环；失败不缩小区域。
- 对边界同时事件、重复传感器峰、双面速度仲裁分别验证所选实现策略。
