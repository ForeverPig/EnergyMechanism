# JW5026：24V输入、5V/1A输出外围计算

设计对象：`Netlist_Schematic1_2026-10-29.enet`中的独立STM32/ESP32/五路CAN板。

用户已明确：灯开关控制线、MCP2515中断稍后在PCB阶段补接；GND/PGND在PCB桥接；更换JW5026；去掉原电源或合二极管，但保留USB单独给整板供电。

本文件给出建议配置和静态计算，没有修改原理图、网表、PCB或固件。PCB桥接和补线属于用户后续实施计划，本次未验证完成。

## 1. 依据与设计目标

依据JoulWatt原厂《JW5026》Rev.1.02（2020-07-14），由供应商提供的原厂PDF：

[JW5026数据手册](https://datasheet.lcsc.com/datasheet/pdf/f83872ed2237628ee0705043f9e45a8d.pdf?productCode=C185109)。

芯片为4.7～40V输入、1A同步降压，标称开关频率1.1MHz，手册列出0.75～1.25MHz。内置上下桥MOS，不需要外置续流肖特基。手册第10页直接给出24V→5V/1A应用。

目标为5V逻辑总线：供给五个TJA1051及后级3.3V LDO。按1A设计外围；两路24V/100mA灯直接取VIN，不计入此5V输出电流。1A额定及计算不代表实际PCB满载温升已验证。

## 2. 推荐配置及旧位号对照

| 元件/作用 | 推荐值与规格 | 对旧板的处理 |
| --- | --- | --- |
| U22 | JW5026SOTB#TRPBF，SOT23-6 | 替换LMR16006YDDCR，更新符号及料号并核对封装 |
| L2输出电感 | 10µH，±20%，屏蔽型；温升额定电流至少1.5A、优先2A；Isat建议≥2.5A；DCR≤100mΩ、优先更低 | 原47µH、饱和1A电感更换 |
| R16，输出→FB上臂 | 11.0kΩ，1%，0402 | 原54.9kΩ更换 |
| R34，FB→GND下臂 | 2.10kΩ，1%，0402 | 原10kΩ更换 |
| R33，VIN→EN | 100kΩ，1%，0402 | 原10kΩ改为100kΩ，按厂家常开参考电路 |
| C35，BST→SW | 100nF，≥10V，X7R/X5R | 原100nF可保留，必须靠近芯片 |

| D8、D9，原两路供电或合 | 用低压降电源切换/防反灌方案替换 | 不允许两处均短接造成USB与BUCK并联 |

如24V输入需热插拔，可按厂家建议在入口增加47µF/50V电解作为储能，并结合线缆/电源确认瞬态；电解并不保证把尖峰限制到40V以内。

输出10µF×2是工程起始配置，厂商参考为10µF。更换电容时，应使用其直流偏压曲线确认有效容量，不能以标称值代替。原0402封装的高容量电容不能直接视作大封装同容量的等效替代。

## 3. 引脚连接

| JW5026引脚 | 连接 |
| --- | --- |
| 1 BST | C35一端；C35另一端接6脚SW |
| 2 GND | 电源地；输入/输出电容负端就近回此地，反馈下臂取干净参考点 |
| 3 FB | R16与R34中点 |
| 4 EN | 经R33=100kΩ接24V VIN |
| 5 VIN | 24V输入，C39/C40/C41就近接地 |
| 6 SW | L2输入端和C35另一端 |

L2输出端定义为`5V_BUCK`，C42/C43/C45从此点接地，R16从此点取样。反馈应取在电源MUX之前的BUCK输出，不能跨到USB或MUX输出去取样。

该六脚功能顺序与原LMR16006相符，但仍须替换真实器件、核对库焊盘和Pin 1方向，不能只修改显示名称。

## 4. 反馈计算

`VOUT = 0.8 × (1 + R16/R34)`

`R16/R34 = 5/0.8 − 1 = 5.25`

采用11.0kΩ和2.10kΩ：

`VOUT = 0.8 × (1 + 11.0/2.10) = 4.99048V`。

原54.9kΩ/10kΩ若直接沿用，换成0.8V基准后约为5.192V，不能继续把原反馈计算当作5.00V。

手册参考使用11.2kΩ/2.1kΩ，标称约5.067V；本方案为更贴近5.00V选择11.0kΩ。4.990V是标称值，器件本身反馈基准误差不能靠精密电阻消除。

只按手册0.78～0.82V基准范围以及两颗独立1%电阻的极端组合计算，约为4.785～5.202V；这不是包含所有温度、纹波、动态及布线误差的整板保证范围。需要更小的分压误差可用0.1%电阻，但仍受芯片基准精度限制。

## 5. 电感计算

按24V→5V、1A，稳态理想占空比约0.2083：

`ΔIL = VOUT × (1 − VOUT/VIN) / (fSW × L)`

| 工况 | ΔIL峰峰值 | 1A负载下峰值 |
| --- | --- | --- |
| 1.1MHz，10µH | 0.360A | 1.180A |
| 0.75MHz，10µH | 0.528A | 1.264A |
| 0.75MHz，8µH（−20%电感） | 0.660A | 1.330A |

这说明10µH足以作为正常1A工况的起点。饱和电流不能只按1A平均负载选择；2.5A建议还为器件限流涉及的约2A级电流、温度和容差留出余量。应核对所选电感在热态下的饱和定义和温升曲线。

原47µH/Isat=1A电感不建议继续使用：在1A平均电流下，任意正纹波已经会使峰值高于1A，其故障电流配合也不足。

## 6. 电容与纹波估算

满载时输入陶瓷电容的RMS纹波电流约：

`ICIN_RMS ≈ IOUT × sqrt(D × (1−D)) = 0.406A`。

若允许纯电容项输入纹波100mV、频率取0.75MHz：

`CIN_eff ≥ IOUT × D × (1−D)/(fSW × ΔVIN) ≈ 2.20µF`。

本方案要求有效输入总容量≥4.7µF，按同一简化模型，纯电容项纹波约47mV。实际还要加ESR、ESL及布线尖峰。

若输出有效容量为10µF，忽略ESR：

`ΔVOUT_C ≈ ΔIL/(8 × fSW × COUT_eff)`。

标称1.1MHz/10µH时约4.1mVpp；0.75MHz/8µH时约11.0mVpp。以上仅为理想稳态电容项，并非实际测得的纹波。Wi-Fi突发和多路CAN负载阶跃需另看控制环响应，不能据此保证瞬态压降。

## 7. USB独立供电：D8/D9的位置需要切换器件

用户确认保留USB单独给整板供电，因此不能把原D8、D9都短接。直接短接会将USB VBUS与同步降压输出硬并联，产生电源竞争和回灌风险。

建议的连接结构：

`24V → JW5026 → 5V_BUCK → 电源MUX输入1`

`USB VBUS → 电源MUX输入2`

`电源MUX输出 → SYS_5V → 五个CAN收发器、3.3V LDO、其余5V负载`

可选TPS2116这一类带反向电流阻断的低压降电源MUX；将BUCK设为优先源。TPS2116额定输入1.6～5.5V、连续2.5A、典型导通电阻40mΩ，在0.8A时典型压降约32mV，在1A时约40mV。实际上下限和切换门限按其手册完整配置，不将典型压降当保证值。本文件未展开其全部外围BOM。

来源：[TI TPS2116手册](https://www.ti.com/lit/ds/symlink/tps2116.pdf)。

USB来源仍需要具备整板所需的电流能力；安装1A降压器不会提高USB端口本身的可供电流。需保留USB-C的CC识别和接口保护。

## 8. 布局与验证边界

- C39/C40/C41紧靠5脚VIN与2脚GND，减小输入高频环路。
- C35紧靠BST/SW；SW铜面积适度，远离FB和ESP天线区域。
- R16/R34紧靠FB；反馈从BUCK输出电容正端取，地参考避开脉冲回流。
- 用户计划的GND/PGND桥接应在最终PCB明确体现，并回读/检查连接；本次不宣称已经桥接。
- JW5026输入工作上限40V，比原LMR16006的60V低，24V热插拔/线缆瞬态应单独核对。
- 1A是器件额定，不是本板热验证结果。按典型上下管电阻计算，1A时仅导通损耗已约0.28W，另有开关/驱动等损耗；SOT23封装需要有效铺铜和样板温升验证。

样板建议检查24V供电、USB单独供电及双源同时接入时的系统5V、切换与回灌；再覆盖Wi-Fi发射和多路CAN同时活动的负载工况。
