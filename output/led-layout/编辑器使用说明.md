# 灯板对称布局编辑器

用 Edge、Chrome 或 Firefox 打开同目录的 **editor.html**。这是完整的离线程序，复制这一个文件就能运行，不需要服务器、安装或联网。原有 `preview.html` 和默认坐标文件保留。

`editor-shell.html` 是构建用的源模板，不含完整样式和程序。误打开它时会跳转到同目录的 `editor.html`；复制给其他电脑时只需复制完整的 `editor.html`。

## 调整灯位

- 初始为308颗5050、24颗小灯、332个100 nF／0402电容和16个安装孔。最外圈R142.5 mm的8颗小灯已原位转换为5050，最外圈共有64颗大灯；LED编号和极角保留，配对电容按大灯关系摆放。
- 滚轮缩放，空白处按住拖动平移；“整板”恢复全板视图。
- 点击灯珠显示当前位号、中心、环号和联动组。可直接拖灯，也可以输入所选灯的**全局极角**并点“应用极角”；0°为+X，90°为+Y，逆时针增加。
- 位号定位会放大到该灯附近。调角和改数量后编号会更新，所选对象由内部稳定标识跟踪。
- 普通位置按 `±θ + k×90°` 联动8颗，半径固定。X/Y轴上的4颗大灯固定。45°四灯组拖离这条线时补成8颗及8个电容，该环大灯数增加4颗，其他灯位不重排。
- 八灯组代表角限制为0.01°～44.99°，不会因拖到对称边界而自动减灯。再次改环数量可恢复均匀分布。
- 每环大灯至少4颗且为4的倍数。修改表中数量并点“应用”，仅该环大灯均匀重排；该环先前的大灯调角会清除。小灯数量与已调角度不变。
- 大灯电容局部偏移为(-3.2,+3.6) mm，小灯为(+0.3,-2.2) mm；电容角度为LED角度加180°。只随LED平移和旋转，不自动避让，不镜像封装。
- 对称约束针对LED中心；每颗灯的电容保留自己的局部供电脚关系。
- 红色表示本体／假定包络冲突、板边越界或小灯离开十字区域。总灯数超出300～399也会提示。草稿仍可导出；检查不代表实际PCB DRC通过。

撤销／重做支持按钮和Ctrl+Z／Ctrl+Y，每次完整拖动记为一步。浏览器可用时会自动保存项目；若浏览器阻止本地存储，页面会提示保存JSON。

## 保存与导出

“保存项目JSON”导出可再次编辑的完整项目，包括对称组、极角、数量、内部标识、电容局部关系和封装预设。“载入项目”恢复这些内容；无效项目不会替换当前布局。

编辑器项目格式现为版本2。打开原有版本1自动保存或载入旧项目JSON时，最外圈小灯组会自动转换为5050，保留已调极角、内部标识和其他环的数量。旧布局／PCB参考文件保留；当前布局坐标请使用编辑器导出。

“导出嘉立创坐标”下载 `energy-jlceda-positions.csv`，含LED、电容和安装孔的 `Designator,Mid X,Mid Y,Rotation`，单位mm，圆心原点，Y向上。该按钮导出的文件**已经补偿封装中心偏移**。其他导出包括本体中心坐标、编号变化对照、小灯位号和链序CSV。

编号内圈到外圈、圈内逆时针，小灯混排进链序，`LEDn`对应`Cn`。R82.5、R97.5、R112.5均从+X轴下侧小灯开始。编号变化对照相对于项目初始332颗布局；`NEW`为新增，`DELETED`为删除。内部标识不会因位号改变而改变。

2026-10-13调整R112.5圈入口：默认布局原LED216改为LED165，原LED165～LED215各加1；LED1～LED164及LED217～LED332不变，对应电容同样改号。仅改编号，所有灯、电容的位置和角度不变。旧自动保存和项目JSON通过稳定标识保留已调位置，刷新后采用新的链序。改数量后的实际编号以编辑器导出为准。

嘉立创的坐标导入定位**已经存在且位号匹配**的元件，不会自动新增、删除元件或改变网络。改数量或链序后，先处理元件数量、位号和连线，再导入坐标。原目录的旧 `jlceda-positions.csv` 是旧导出格式，不能代替新编辑器下载的补偿坐标文件。

## 封装预设

默认预设来自2026-10-03保存的PCB工程：5050封装包含4个贴片焊盘和侧面GND通孔，小灯使用当前2020封装，电容为0402。预设记录封装本体中心与全部焊盘中心，坐标在**封装0°局部坐标系**中，单位mm。

导出时先按每个元件的实际角度旋转全部焊盘中心，再求其X/Y极值中点，并相对于本体中心计算补偿。采用旋转后的范围，不把0°补偿简单旋转到所有角度。

更换库封装后，展开“封装预设与导出基准”，导出预设JSON，在正确的封装0°坐标系中更新 `bodyCenter` 与 `padCenters`，再点“更换预设”载入。四类键为 `5050`、`small`、`capacitor`、`screw`，例如：

```json
{
  "name": "所选封装名称",
  "bodyCenter": [0, 0],
  "padCenters": [[-2.5, -1.6], [-2.5, 1.6], [2.5, -1.6], [2.5, 1.6]]
}
```

这是单类预设的格式例子；导入文件应包含全部四类。焊盘中心要包含封装内的通孔焊盘；本体中心依据本体轮廓，不能把位号文字、引脚标记或侧面通孔纳入本体范围。换封装时仍须确认其0°引脚方位与本编辑器的约定一致。

## 源码和验证

- `editor-model.js`：对称组、稳定标识、数量重排、电容随动、几何检查、补偿坐标导出。
- `editor-ui.js` / `editor-shell.html` / `editor.css`：选择、拖动、缩放、撤销、文件保存与载入。
- `build_editor.py`：读取现有布局及保存工程，生成自包含 `editor.html`、初始数据和封装预设JSON；不修改EDA工程或旧布局导出。
- `check_editor.cjs`：模型检查及真实Edge浏览器操作检查，截图和下载验证放在 `output/playwright`。

重建：`python build_editor.py`。验证：`node check_editor.cjs`；旧预览回归：`node check_preview.cjs`。
